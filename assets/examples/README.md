# Recorded examples

Two receipts from the SROIE test split (ICDAR 2019 Robust Reading Challenge, task 3; licence tag CC-BY-4.0 on the Hugging Face mirror, original terms at https://rrc.cvc.uab.es/?ch=13), neither used in training, with the fine-tuned 7B's recorded output after calibration. `examples.json` also holds the dataset's labels (which contain typos). Regenerate with `python scripts/make_examples.py`.
